# 诵经助手鸿蒙版帮助中心离线接入方案与开发计划

日期：2026-08-20

## 一、目标与范围

在鸿蒙版设置页增加 `app_help_center` 帮助中心，保留本地公告、版本历史、FAQ、已读状态、邮件反馈和技术支持入口。

业务边界：诵经助手自身不请求远程公告、远程 FAQ、远程版本补充或 webhook；允许将 `mailto:` 和 `https:` 链接交给本地邮件 App 或系统浏览器，外部应用是否联网不属于本 App 的联网行为。

## 二、技术方案

- 使用现有 `app_help_center ^0.2.6`，不修改插件 API。
- `refreshRemoteOnOpen` 固定为 `false`，三个远程 URL 均保持 `null`。
- 公告、版本历史和 FAQ 全部随 App 本地打包。
- 不配置 Discord、钉钉、网页表单、评分和截图上传。
- 邮件反馈通过 `HelpFeedbackConfig.submitHandler` 调用现有 `ExternalLauncherTools`。
- 技术支持通过 `onOpenSupport` 调用现有 `ExternalLauncherTools`。
- 不使用插件内置 `email`、`supportUrl` 通道，避免在鸿蒙上直接调用未注册的官方 `url_launcher`。
- 使用插件现有 `shared_preferences` 存储公告与版本已读状态。

## 四、测试用例

- 配置不包含任何远程公告、FAQ 或版本补充 URL。
- `refreshRemoteOnOpen` 为 `false`。
- 反馈只启用自定义邮件回调，不启用 webhook、网页表单或截图。
- 邮件反馈通过 `gongke/external_launcher` 发送正确的 `mailto:` 链接。
- 技术支持通过 `gongke/external_launcher` 发送正确的 `https:` 链接。
- 本地公告、版本历史和 FAQ 可正常读取。
- 设置页可进入帮助中心，未读状态变化后入口同步刷新。

## 五、发布记录

### 已完成

- 设置页新增带未读红点的帮助中心入口。
- 入口对 controller 的构建期通知延迟到帧末处理，避免进入帮助页时触发构建期 `setState`。
- 帮助中心提供本地公告、版本历史、FAQ 和已读状态持久化。
- 反馈表单通过鸿蒙现有 `gongke/external_launcher` 通道打开本地邮件 App。
- 技术支持通过同一通道打开系统浏览器。
- 明确关闭远程公告、远程 FAQ、远程版本补充、webhook、评分和截图上传。
- 未修改 `app_help_center` API。

- `flutter analyze lib/view/help/help_center_page.dart lib/main.dart lib/view/setting/setting_page.dart test/help_center_config_test.dart`：无问题。
